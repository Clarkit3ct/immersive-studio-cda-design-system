Use `Field` for form inputs. The label uses the eyebrow treatment so forms sit inside the brand's typographic voice.

```jsx
<Field label="Email" type="email" placeholder="you@studio.com" />
<Field label="Project" as="textarea" hint="Where is it in the design process?" />
```

Focus draws a `--focus-ring` outline and darkens the border; there is no glow, no shadow, no color fill.
